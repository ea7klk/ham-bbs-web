HAMNET RADIO BBS · design review

Four directions for the web BBS

Each mockup is a static, responsive page using the real content and data the board actually holds — boards, bulletins, APRS traffic, the station directory. They were the shortlist; the live site now carries the blend of 04 and 03.

Chosen: 04's structure with 03's palette. The live board now uses Packet Manual's layout — monospace, hard rules, ruled tables, a title block — lit with Spectrum's colours. These four pages are kept as the record of the choice, not as a shortlist.
01 — Front Panel

Front Panel

Dark, instrument-like: phosphor green, amber highlights, an S-meter status strip and a waterfall trace. Reads like the front of a transceiver.

darktechnicalmono accents
02 — QSL Desk

QSL Desk

Light and editorial: warm paper, navy and a single red accent, serif headlines and operators presented as QSL cards with grid squares.

lighteditorialserif
03 — Spectrum

Spectrum

Modern and colourful: indigo-to-magenta gradients, frosted glass tiles, a bento dashboard and a live-looking band-activity spectrum.

darkgradientdashboard
04 — Packet Manual

Packet Manual

Bright and blunt: monospace throughout, heavy black rules, signal-orange accents, ruled tables and a title block. Honours the BBS lineage without pretending to be a terminal.

lightbrutalistmono

All four are static HTML with inline CSS and no external assets, so they load over HamNet with nothing to fetch. They are served by the BBS itself, not by a separate site.
